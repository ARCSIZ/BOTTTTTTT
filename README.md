# COTTAVEN RP — Бот предложки и модерации постов (Bothost.ru)

Готовый асинхронный Telegram-бот на базе **aiogram 3.25+** с поддержкой:
- Отправки постов в чат модерации (включая **форум-чаты с топиками**).
- Полного сохранения **любого форматирования** Telegram (`entities` / `caption_entities`: жирный, курсив, спойлеры, цитаты, ссылки, моноширинный текст и **Telegram Premium Emoji**).
- Прикрепления **до 10 фотографий** в одном посте (медиагруппы / альбомы с автоматической склейкой).
- Конструктора **Inline-кнопок** с поддержкой новых цветов и стилей кнопок Telegram Bot API 9.4+ (`style`: `primary` — синяя, `success` — зелёная, `danger` — красная, или стандартная) и URL-ссылок.
- Автоматической подписи в конце каждого опубликованного поста:
  `COTTAVEN RP • Подписаться` (со ссылкой из `CHANNEL_LINK` на основной канал для обоих ТГК).
- Системы администраторов (добавление/удаление через команды владельцем) с сохранением в SQLite.

## Инструкция по запуску на Bothost.ru

1. Создайте нового бота на **bothost.ru** (выберите язык **Python**).
2. Загрузите файлы `bot.py` и `requirements.txt` в корень проекта (или распакуйте архив).
3. В панели управления Bothost перейдите в раздел **Переменные окружения (Environment Variables)** и добавьте:
   - `BOT_TOKEN` — токен вашего бота от `@BotFather`
   - `OWNER_ID` — ваш цифровой Telegram ID (главный владелец)
   - `CHANNEL_ID` — ID основного ТГК (например, `-1001234567890`)
   - `RP_CHANNEL_ID` — ID ТГК для РП новостей (например, `-1009876543210`)
   - `CHANNEL_LINK` — публичная или пригласительная ссылка на основной канал (например, `https://t.me/cottaven_rp`)
   - `MOD_CHAT_ID` — *(необязательно сразу)* ID чата модераторов. Можно также просто прописать `/setmod` прямо в нужном топике чата!
   - `MOD_TOPIC_ID` — *(необязательно сразу)* ID топика в чате модераторов (если используется `/setmod`, подставится автоматически).
4. Убедитесь, что в настройках запуска Bothost основным файлом указан `bot.py`.
5. Добавьте бота в **оба канала** и в **чат модерации** с правами администратора (публикация сообщений и управление сообщениями).
6. Нажмите **Запустить / Перезапустить** в панели Bothost.

## Команды бота

### Для владельца (`OWNER_ID`):
- `/addadmin <ID или ответ на сообщение>` — назначить администратора бота.
- `/deladmin <ID или ответ на сообщение>` — снять администратора бота.
- `/admins` — список всех действующих администраторов.
- `/setmod` — привязать текущий чат (и текущий топик, если команда вызвана внутри темы форума) как место для проверки постов.

### Для пользователей:
- `/start` — главное меню и создание поста.
- `/cancel` — отменить текущее создание поста.
